# Make the AI Judge Laugh: The Office Joke Open

A make.fun bounty entry. `main.py` (Python 3, stdlib only, no network) writes
a single original one-line office joke to `/output/entry.txt`:

> The printer jammed again, so I emailed IT, who replied-all that the printer is fine — from the printer's own email address.

The line is 123 characters, deterministic, and validated before writing
(non-empty, single line, within the 200-character limit).
